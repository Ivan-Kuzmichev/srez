# Пакет для реализации

Всё, что нужно, чтобы начать разработку Srez, сервиса анализа инвестиций, в Claude Code на Next.js. Этот файл для тебя. Claude Code начинает с `CLAUDE.md`.

  02-architecture.md      стек, процессы, каталоги, деплой

## Как начать

1. Пакет уже лежит в корне папки проекта. Файл `README.md` по запуску Claude Code напишет сам в фазе 0.
2. Ответь на открытые вопросы ниже, хотя бы на первые три, и впиши ответы в `docs/PROGRESS.md`.
3. Открой папку проекта в Claude Code и вставь первый запрос из `docs/10-prompts.md`.
4. Прочитай план, который он предложит, и подтверди.

Дальше — по фазе за раз, запросами из того же файла.

## Что решено за тебя

Эти решения зашиты в документы. Если с чем-то не согласен, поправь до старта: потом дороже.

| Решение | Почему |
|---|---|
| PostgreSQL и Drizzle | Точные числа в `numeric`, миграции в репозитории |
| Отдельный воркер на pg-boss, без Redis | Синхронизация и расчёты не должны жить в веб-процессе. Очередь в той же базе, лишнего контейнера нет |
| Better Auth | Логин, 2FA и пасскеи готовыми плагинами |
| Журнал операций — источник правды | Позиции и доходность всегда можно пересчитать |
| Портфель — выборка по счетам и тегам | Один счёт делится между портфелями |
| Тег задаётся правилом на бумагу в счёте | Автоимпорт сам раскладывает сделки по портфелям |
| REST API Т-Инвестиций через fetch | Без сторонних SDK и gRPC |
| Только публичные узлы блокчейна | Твоё решение |
| Название Srez, знак — круг с отодвинутым сектором | Твоё решение. Файлы знака в `design/logo.svg` и `design/logo-icon.svg` |
| Один пользователь, но `user_id` во всех таблицах | Второй пользователь позже без переделки схемы |
| Регистрации нет, пользователь создаётся командой | Меньше поверхность атаки |
| API только на чтение плюс запуск синка | Запись через API отложена |
| Крипта восьмой фазой | Ядро и Т-Инвестиции важнее, а по EVM есть нерешённый вопрос |

## Открытые вопросы

1. **Доступ к API Т-Инвестиций.** Проверь с NAS: `curl -I https://invest-public-api.tbank.ru`. Если не отвечает, понадобится прокси, для него есть переменная `TINVEST_PROXY_URL`.
2. **HTTPS-адрес сервиса.** Пасскеи работают только по HTTPS и по доменному имени, не по IP. Нужен адрес вроде `https://invest.<твой домен>` через обратный прокси. Без этого вход по пасскею будет скрыт, остальное работает.
3. **Сети крипты в первой версии.** По умолчанию Bitcoin, Ethereum, Arbitrum, Base.
4. **История транзакций EVM.** Публичный узел отдаёт балансы, но не список операций по адресу. Для истории нужен API обозревателя блоков. Варианты описаны в `docs/05-integrations.md`, решить перед восьмой фазой.

## Чего в пакете нет

- Кода. Его пишет Claude Code по плану.
- Макетов для мелких диалогов и состояний загрузки. Их список в `docs/08-ui.md`, раздел 5: делаются по аналогии.
- Проверки макетов в браузере с моей стороны: разметка проверена на целостность, отрисовку я не смотрел.

По документации я сверил только адрес и формат REST API Т-Инвестиций, состав плагинов Better Auth и текущую ветку Next.js. Остальные внешние API (Московская биржа, Банк России, CoinGecko, обозреватели блоков, Telegram) описаны без проверки. Claude Code обязан сверять всё перед реализацией, это правило есть в `CLAUDE.md`.
