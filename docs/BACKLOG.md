# Отложено

Сюда попадает всё, что не входит в первую версию. Ничего из этого не делать без прямого запроса владельца. Новые идеи дописывать в конец с датой.

## Источники данных

- Импорт CSV: сопоставление колонок, предпросмотр, отчёты других брокеров.
- Криптобиржи по API-ключу только на чтение.
- xpub для Bitcoin: все адреса кошелька одной записью.
- Сети Solana, TON, Tron.
- История EVM для сетей сверх первых трёх.
- Свои узлы блокчейна. Владелец решил использовать только публичные.

## Контроль

- Сверка выплат: предупреждать, если ожидаемый купон или дивиденд не пришёл или сумма не сошлась.
- Лента событий по бумагам: сплиты, оферты, смена тикера, делистинг.
- Срез стоимости на произвольную дату, например на 1 января.
- Лента уведомлений в интерфейсе.

## Планирование

- Цели: сумма к дате, пассивный доход против расходов, прогноз по темпу.
- План регулярных покупок с напоминаниями.
- Стресс-тест: падение акций, курса, рост ставки.
- «А если бы индекс»: те же пополнения в те же даты, вложенные в индекс или вклад.

## Удобство

- Дневник сделок: заметка «почему купил» и напоминание пересмотреть.
- Список наблюдения с целевыми ценами.
- Доступ только на чтение для второго человека.
- Интерфейс управления пользователями.
- Светлая тема.
- Раскрытие состава фондов.
- Учёт всего капитала: недвижимость, долги.
- Бэктесты, налоговые отчёты.

## API

- Методы записи под правом `write:data`.
- Встроенный MCP-сервер поверх `/api/v1`.

## Найдено в фазе 3

- Ручная покупка без пополнения счёта уводит кэш счёта в минус (так и задумано: деньги пришли извне, но этого не видно). Можно добавить в форму операции флажок «деньги пришли со стороны», который создаёт парное пополнение. Обсудить с владельцем.

## Найдено в фазе 4

- SOCKS5-прокси для Т-Инвестиций. Сейчас поддержан только HTTP-прокси (CONNECT); с NAS владельца API доступен напрямую.
- Паи фондов с заблокированными активами выводятся дробными («225.46349 лотов»), а `quantity` в операции целое. Остаток в долях пая останется расхождением сверки; если таких случаев станет больше, разбирать по описанию операции или брокерскому отчёту (`GetBrokerReport`).
