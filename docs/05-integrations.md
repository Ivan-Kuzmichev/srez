# Интеграции

Перед реализацией каждой интеграции открой её актуальную документацию и сверь пути, поля и лимиты. Расхождения с этим файлом запиши в `PROGRESS.md` и поправь файл.

Общие правила для всех клиентов:

- Таймаут запроса 10 секунд. До 3 попыток с паузами 1, 5, 30 секунд на сетевые ошибки, 429 и 5xx. На 4xx, кроме 429, не повторять.
- Ответ проверяется Zod-схемой. Лишние поля допускаются, отсутствие обязательных — ошибка интеграции.
- Каждый запрос пишется в лог с источником, методом, статусом и длительностью. Тело — только в режиме отладки, в `raw_responses`, с вырезанными секретами.
- Клиент не знает о базе. Тесты на записанных ответах, без сети.

## 1. Т-Инвестиции

Документация: https://developer.tbank.ru/invest/intro/intro/

- REST-шлюз: `POST https://invest-public-api.tbank.ru/rest/tinkoff.public.invest.api.contract.v1.<Сервис>/<Метод>`, тело JSON.
- Заголовок `Authorization: Bearer <токен>`.
- Токен пользователь выпускает сам, с доступом только для чтения. Сервис не вызывает ни одного метода, меняющего что-либо у брокера.
- Лимиты динамические, зависят от сервиса. При 429 ждать и повторять. Текущие лимиты отдаёт метод тарифа пользователя.
- Прокси: если задан `TINVEST_PROXY_URL`, все запросы этого клиента идут через него. Остальные интеграции прокси не используют.

Нужные методы (названия сверить):

| Задача | Сервис и метод |
|---|---|
| Проверка токена, список счетов | `UsersService/GetAccounts` |
| Лимиты | `UsersService/GetUserTariff` |
| Операции с пагинацией | `OperationsService/GetOperationsByCursor` |
| Текущие позиции для сверки | `OperationsService/GetPositions` |
| Справочник бумаги | `InstrumentsService/GetInstrumentBy`, `FindInstrument` |
| Купоны облигации | `InstrumentsService/GetBondCoupons` |
| Дивиденды | `InstrumentsService/GetDividends` |
| Последние цены | `MarketDataService/GetLastPrices` |
| История дневных цен | `MarketDataService/GetCandles` |

Особенности:

- Деньги и количества приходят парами `units` и `nano`. Перевод: `units + nano / 1e9`, сразу в `Decimal`.
- `GetOperationsByCursor`: до 1000 записей за запрос, дальше по курсору. Брать только исполненные операции.
- Первая загрузка: по каждому счёту с даты открытия, окнами по году, чтобы показывать прогресс в мастере.
- Дальнейшие: с даты последней известной операции минус 3 дня. Дубли отсекает уникальный индекс.
- Комиссия брокера приходит отдельной операцией со ссылкой на сделку. При импорте она кладётся в поле `fee` сделки, отдельная операция не создаётся. Комиссии без родительской сделки (обслуживание, маржа) создаются как `fee`.
- Налог приходит отдельной операцией: создаётся как `tax`, а если есть ссылка на выплату — кладётся в её поле `tax`.

Соответствие типов операций. Таблица неполная: для каждого значения перечисления из документации должно быть явное правило, неизвестный тип импортируется как `other` с предупреждением в лог.

| У брокера | У нас |
|---|---|
| Покупка, покупка с карты | `buy` |
| Продажа | `sell` |
| Дивиденды | `dividend` |
| Купон | `coupon` |
| Погашение облигации | `redemption` |
| Частичное погашение | `amortization` |
| Пополнение счёта | `deposit` |
| Вывод средств | `withdrawal` |
| Комиссия брокера | поле `fee` или `fee` |
| Налог, корректировка налога | поле `tax` или `tax` |
| Покупка и продажа валюты | `fx_buy`, `fx_sell` |
| Ввод и вывод бумаг | `transfer_in`, `transfer_out` |

Ошибки для интерфейса:

| Код | Текст |
|---|---|
| 401 | Токен не найден или отозван. Выпустите новый |
| 403 | У токена нет доступа к этому счёту |
| 429 | Слишком много запросов, повторим позже |
| сеть, 5xx | Т-Инвестиции не отвечают, повторим через N минут |

Проверка «только чтение»: если API позволяет узнать права токена, мастер отклоняет токен с полным доступом. Если не позволяет — мастер показывает предупреждение, а код гарантирует, что торговые методы не вызываются (в клиенте их просто нет).

## 2. Цены бумаг и бенчмарки

- Текущие и исторические цены бумаг — из Т-Инвестиций.
- Индексы для бенчмарка (индекс МосБиржи полной доходности, индекс гособлигаций) — публичный ISS Московской биржи: https://iss.moex.com/iss/reference/. Индекс заводится как инструмент вида `index`, история кладётся в `prices`.
- При первом появлении бумаги история цен догружается с даты первой операции.

## 3. Курсы валют

Официальные курсы Банка России: https://www.cbr.ru/development/SXML/. Раз в сутки, плюс догрузка истории с даты первой операции. Хранится курс к рублю.

## 4. Цены крипты

CoinGecko: https://docs.coingecko.com/. Текущие цены пачкой по списку монет, история по дням для новых монет. Бесплатный доступ ограничен по частоте: запросы объединять, результат кэшировать в `prices`. Ключ API необязателен, хранится в `secrets`.

Наружу уходит только список идентификаторов монет, не адреса.

## 5. Блокчейны

Только публичные точки доступа, без своих узлов. Интерфейс провайдера один на все сети:

```ts
interface ChainProvider {
  family: 'bitcoin' | 'evm'
  validateAddress(address: string): boolean
  getBalances(address: string, network: string): Promise<TokenBalance[]>
  getTransfers(address: string, network: string, sinceBlock?: number): Promise<Transfer[]>
  health(network: string): Promise<{ ok: boolean; latencyMs: number }>
}
```

Первая версия:

- **Bitcoin.** Публичный API в формате Esplora (например, mempool.space): баланс адреса и список транзакций.
- **EVM (Ethereum, Arbitrum, Base).** Баланс нативной монеты и известных токенов — через публичный RPC пачкой вызовов. История переводов и поиск неизвестных токенов через RPC невозможны: нужен API обозревателя блоков.

Перед фазой крипты нужно короткое исследование и решение владельца: какой API обозревателя использовать для истории EVM (Blockscout-совместимый без ключа или Etherscan с бесплатным ключом). До решения режим «только балансы» работает на RPC и списке известных токенов.

Остальное:

- Список публичных точек доступа на сеть лежит в конфиге, с запасными. При отказе одной берётся следующая.
- Адрес кошелька уходит оператору точки доступа. Это показано пользователю на экране добавления.
- Спам: токен без цены или не из списка известных скрывается. Остаток дешевле порога из настроек скрывается.
- Реестр доходных токенов — файл конфигурации: адрес контракта, сеть, вид (`rebasing` или `wrapped`), базовая монета, способ получить курс обёртки. На старте: aTokens Aave и stETH как `rebasing`, wstETH и rETH как `wrapped`.
- Solana, TON, Tron в выборе сети показываются, но отключены до появления провайдера. Они в `BACKLOG.md`.

## 6. Telegram

Bot API: https://core.telegram.org/bots/api. Только `sendMessage`. Токен бота и `chat_id` вводятся в настройках, токен шифруется. Кнопка «Отправить проверочное сообщение». Сообщения короткие, без сумм, если включено «скрывать суммы».

## 7. Куда сервис ходит наружу

Полный список хостов. Любой новый хост — через согласование.

- `invest-public-api.tbank.ru`
- `iss.moex.com`
- `www.cbr.ru`
- `api.coingecko.com`
- публичные точки доступа блокчейнов из конфига
