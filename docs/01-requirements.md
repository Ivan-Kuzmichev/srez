# Требования

## 1. Контекст

- Один владелец, он же администратор. Регистрации нет. Схема данных при этом хранит `user_id`, чтобы второй пользователь позже не потребовал миграции всего.
- Self-hosted: Docker Compose на домашнем NAS. Белого IP дома нет, доступ из локальной сети или через VPN.
- Источник биржевых данных на старте один: Т-Инвестиции, токен только для чтения. Сервис ничего не покупает и не продаёт.
- Крипта: ручной ввод и кошельки по публичному адресу через публичные узлы.
- Основная валюта отчётов — рубль, дополнительно доллар и евро.
- Интерфейс на русском, тёмная тема, две раскладки: широкая с боковым меню и телефонная с нижней панелью.

## 2. Словарь

| Термин | Значение |
|---|---|
| Источник | Откуда приходят данные: Т-Инвестиции, кошелёк по адресу, ручной ввод |
| Счёт | Контейнер активов внутри источника: брокерский, ИИС, кошелёк, вклад |
| Инструмент (актив) | То, чем владеют: акция, облигация, фонд, валюта, монета, свой актив |
| Операция | Запись журнала: покупка, продажа, выплата, пополнение, комиссия и т. д. |
| Позиция | Количество инструмента на счёте, выведенное из операций |
| Тег | Метка на операциях и позициях. Делит один счёт между портфелями |
| Портфель | Выборка: набор правил «счёт целиком» или «счёт по тегу». Не контейнер |
| Снимок | Стоимость позиций на конец дня |
| Начисление | Доход, который остаётся в позиции (Aave, Lido), раз в сутки |
| Сверка | Сравнение количества из журнала с тем, что отдаёт брокер |

## 3. Функциональные требования

Формат идентификатора: `FR-<модуль>-<номер>`. Ссылайся на них в коммитах и в `PROGRESS.md`.

### AUTH — вход и безопасность

- FR-AUTH-1. Вход по логину и паролю.
- FR-AUTH-2. Двухфакторная защита TOTP: подключение через QR и ключ, 10 одноразовых резервных кодов, отключение.
- FR-AUTH-3. Вход по пасскею. Пасскей заменяет и пароль, и код.
- FR-AUTH-4. «Запомнить устройство на 30 дней»: длинная сессия и пропуск кода на этом устройстве.
- FR-AUTH-5. Блокировка входа по паролю на 15 минут после 5 неудачных попыток подряд. Пасскей при блокировке работает. Счётчик оставшихся попыток показывается.
- FR-AUTH-6. Список пасскеев: добавить, удалить, дата последнего входа.
- FR-AUTH-7. Список активных сессий: завершить одну, завершить все, кроме текущей.
- FR-AUTH-8. Смена пароля из настроек. Сброс пароля только командой на сервере.
- FR-AUTH-9. Первый пользователь создаётся командой CLI. Экран регистрации отсутствует.
- FR-AUTH-10. Входы и неудачные попытки пишутся в лог с источником `auth`.

### ONB — первый запуск

- FR-ONB-1. Мастер из четырёх шагов: токен, выбор счетов и глубины истории, загрузка, результат сверки.
- FR-ONB-2. Токен проверяется запросом к API. При ошибке показывается причина.
- FR-ONB-3. Загрузка идёт в воркере. Страницу можно закрыть, прогресс восстанавливается при возврате.
- FR-ONB-4. Пока данных нет, обзор и журнал показывают пустые состояния со входами в мастер, добавление кошелька и ручной ввод.

### SRC — источники и синхронизация

- FR-SRC-1. Источник Т-Инвестиций: статус, расписание (по умолчанию каждые 15 минут), время последнего синка, число операций, выбор счетов для синхронизации.
- FR-SRC-2. Ручной запуск синхронизации. Замена токена.
- FR-SRC-3. Журнал синхронизаций: время, результат, число новых операций, текст ошибки.
- FR-SRC-4. При ошибке повтор с нарастающей паузой, не более 3 попыток на запуск.
- FR-SRC-5. Ручные счета: создание, список, число операций.
- FR-SRC-6. Статус синхронизации виден в боковом меню на всех экранах.

### REC — сверка

- FR-REC-1. После каждого синка количество по каждой бумаге из журнала сравнивается с позициями брокера.
- FR-REC-2. Расхождения сохраняются со статусом и догадкой о причине: перевод бумаг, обмен валюты, погашение, сплит, неизвестно.
- FR-REC-3. Экран разбора: список расхождений, для выбранного — журнал против брокера, операции по бумаге, варианты исправления.
- FR-REC-4. Исправление создаёт ручную операцию с происхождением `reconcile`, её можно отменить.
- FR-REC-5. Бумагу можно исключить из сверки. Расхождение можно отложить.

### OPS — операции

- FR-OPS-1. Журнал: поиск по тикеру и названию, фильтры по типу, счёту, источнику, периоду, постраничная загрузка.
- FR-OPS-2. Итоги по выборке: пополнения, покупки, продажи, выплаты, начисления, комиссии.
- FR-OPS-3. Создание операции вручную: тип, счёт, актив, дата и время, количество, цена, валюта, комиссия, тег, заметка.
- FR-OPS-4. Перед сохранением показывается, что изменится: позиция, средняя цена, доля класса в портфеле, предупреждение при выходе за цель.
- FR-OPS-5. Редактирование и удаление ручных операций. Импортированные операции не редактируются, кроме тега и заметки.
- FR-OPS-6. Начисления по крипте свёрнуты в одну строку за месяц с разворотом по дням.
- FR-OPS-7. У каждой операции видно происхождение: Т-Инвестиции, сеть, вручную, сверка.

### AST — активы

- FR-AST-1. Страница актива: позиция, средняя цена, курсовая прибыль, полный результат с выплатами.
- FR-AST-2. График цены с отметками покупок, продаж и выплат, линия средней цены.
- FR-AST-3. Операции по бумаге. В каких портфелях учитывается и с какой долей. Статус лимита.
- FR-AST-4. Свой актив: название, класс, валюта, способ оценки (ручная стоимость или процент годовых).
- FR-AST-5. Смена тега у позиции применяется ко всем операциям этой бумаги на счёте и запоминается как правило для будущих.

### PRT — портфели

- FR-PRT-1. Список портфелей: стоимость, доходность, структура, из чего собран.
- FR-PRT-2. Создание и настройка: название, бенчмарк, для каждого счёта режим «целиком», «по тегу» или «не входит».
- FR-PRT-3. Один счёт может входить в несколько портфелей.
- FR-PRT-4. Целевые доли по классам с проверкой суммы 100 %. Порог предупреждения в процентных пунктах. Режим «без целей».
- FR-PRT-5. Страница портфеля: стоимость, прибыль с разбивкой на курсовую и выплаты, XIRR, отрыв от бенчмарка по TWR.
- FR-PRT-6. График портфеля против бенчмарка за 1М, 6М, 1Г, всё время.
- FR-PRT-7. Блок «Цели и ребаланс»: факт против цели по классам.
- FR-PRT-8. Позиции: количество, средняя, цена, стоимость, доля, результат в деньгах и процентах.
- FR-PRT-9. Удаление портфеля не трогает операции.
- FR-PRT-10. Таблица счетов: источник, стоимость, в какие портфели входит.

### OVR — обзор

- FR-OVR-1. Общая стоимость, изменение за день, вложено, прибыль, XIRR.
- FR-OVR-2. График стоимости против вложенного с выбором периода.
- FR-OVR-3. Структура по классам: акции, облигации, фонды, крипта, кэш и вклады.
- FR-OVR-4. Список портфелей, ближайшие выплаты, последние операции.
- FR-OVR-5. Переключатель валюты отображения: ₽, $, €. Пересчёт по историческим курсам.
- FR-OVR-6. Фильтр по портфелю.

### PAY — выплаты и начисления

- FR-PAY-1. Итоги года: получено, ожидается до конца года, прогноз за год, среднее в месяц.
- FR-PAY-2. Столбцы по месяцам: получено и ожидается.
- FR-PAY-3. Список ожидаемых выплат из расписаний купонов и объявленных дивидендов, с суммой по текущему количеству.
- FR-PAY-4. Список недавно полученных.
- FR-PAY-5. Начисления по крипте отдельной таблицей: способ начисления, за месяц, за год, прогноз по текущей ставке. В итоги выплат не входят.
- FR-PAY-6. Проценты по своим активам с оценкой «процент годовых» попадают в выплаты.

### ANL — аналитика

- FR-ANL-1. Риск: максимальная просадка с датами и сроком восстановления, годовая волатильность, бета к бенчмарку, худший месяц.
- FR-ANL-2. График просадки от максимума.
- FR-ANL-3. Пять крупнейших позиций и их суммарная доля.
- FR-ANL-4. Валюта риска: рубль, отдельные монеты.
- FR-ANL-5. Лимиты: один эмитент, одна акция, крипта. Статус «в норме» или «превышен».
- FR-ANL-6. Облигации: стоимость, средневзвешенная доходность к погашению, дюрация, купоны на 12 месяцев.
- FR-ANL-7. Таблица выпусков, погашения по годам, оценка при изменении ставки на ±1 п.п., доля фиксированного и плавающего купона.
- FR-ANL-8. Прибыль за год: результат продаж, выплаты, комиссии и налоги, итог.
- FR-ANL-9. Закрытые сделки по FIFO или по средней, срок владения, пометка «больше трёх лет».
- FR-ANL-10. Разбивка результата по классам и по сроку владения. Выгрузка в CSV.

### RBL — ребаланс

- FR-RBL-1. Вход: сумма пополнения, режим «только докупать» или «можно продавать», опция «использовать кэш сверх цели».
- FR-RBL-2. Таблица по классам: сейчас, цель, действие, станет, остаток отклонения.
- FR-RBL-3. Предложение по бумагам из уже имеющихся в портфеле, с количеством по текущей цене и лотности.
- FR-RBL-4. Копирование списка и сохранение плана. Экран не даёт рекомендаций, это расчёт.

### CRY — криптокошельки

- FR-CRY-1. Добавление кошелька по публичному адресу: тип сети, адрес с проверкой формата, для EVM выбор сетей.
- FR-CRY-2. Предпросмотр найденного до сохранения: монеты, суммы, число транзакций, дата первой.
- FR-CRY-3. Режим «балансы и история» или «только балансы».
- FR-CRY-4. Скрытие спам-токенов и остатков дешевле порога. Скрытое не входит в стоимость.
- FR-CRY-5. Обнаружение дубля с ручными записями и выбор: заменить транзакциями из сети или оставить.
- FR-CRY-6. Ежедневные начисления по доходным токенам, см. `04-calculations.md`.
- FR-CRY-7. Используются только публичные узлы. Экран настроек показывает их доступность.
- FR-CRY-8. Приватные ключи и сид-фразы не запрашиваются и не принимаются нигде.

### SET — настройки

- FR-SET-1. Расчёт доходности: главный показатель (XIRR или TWR), учёт свободного кэша, вычет комиссий и налогов, бенчмарк по умолчанию.
- FR-SET-2. Валюты: основная и дополнительные.
- FR-SET-3. Цены: частота обновления, время ежедневного снимка.
- FR-SET-4. Лимиты риска.
- FR-SET-5. Крипта: источник цен, порог скрытия остатков.
- FR-SET-6. Выгрузка всех операций в CSV. Резервная копия базы.

### NTF — уведомления

- FR-NTF-1. Telegram: подключение бота, проверочное сообщение.
- FR-NTF-2. События: поступила выплата, ошибка синхронизации, отклонение от цели больше порога, изменение цены за день больше порога, превышение лимита, еженедельная сводка.
- FR-NTF-3. Одно событие не шлётся повторно, пока условие не снялось.

### DEV — отладка и доступ ассистента

- FR-DEV-1. Режим отладки: уровень логов debug, сырые ответы внешних API хранятся 24 часа с вырезанными секретами, в интерфейсе видны внутренние идентификаторы. Автоотключение через заданное время.
- FR-DEV-2. Логирование: уровень, срок хранения, что писать, опция скрывать суммы и количества.
- FR-DEV-3. Экран логов: поиск по тексту и идентификаторам, фильтры по уровню, источнику, периоду, раскрытие записи, копирование, скачивание, автообновление.
- FR-DEV-4. API-токен для ассистента: название, срок, права по пунктам, опция «только из локальной сети», перевыпуск, отзыв, время и адрес последнего запроса.
- FR-DEV-5. REST API `/api/v1` с описанием OpenAPI, см. `06-api.md`.
- FR-DEV-6. Состояние сервиса: база, очередь, внешние API с задержкой, ошибки за сутки, версия.
- FR-DEV-7. «Собрать отчёт о проблеме»: версия, настройки без секретов, состояние источников, последние 500 строк логов одним файлом.

### MOB — телефон

- FR-MOB-1. До ширины 900 px боковое меню заменяется нижней панелью: Обзор, Портфели, Операции, Выплаты, Ещё.
- FR-MOB-2. Таблицы становятся списками в две строки.
- FR-MOB-3. На экранах с сохранением внизу закреплена полоса действий.
- FR-MOB-4. Все разделы доступны с телефона.

## 4. Нефункциональные требования

- NFR-1. Безопасность: см. `07-auth-security.md`. Секреты зашифрованы, сессии в httpOnly-куках, все мутации с проверкой сессии.
- NFR-2. Приватность: наружу уходят только запросы к перечисленным в `05-integrations.md` хостам. Телеметрии нет.
- NFR-3. Точность: расчёты в десятичной арифметике, эталонные тесты проходят.
- NFR-4. Производительность: любой экран открывается быстрее 1 секунды на 20 000 операций и 5 годах снимков на железе уровня NAS. Тяжёлое считается в воркере и кладётся в базу.
- NFR-5. Надёжность: синхронизация идемпотентна, падение воркера не теряет задачи, повторный запуск безопасен.
- NFR-6. Наблюдаемость: у каждого запроса и задачи есть идентификатор, он есть в логах.
- NFR-7. Доступность: навигация с клавиатуры, видимый фокус, подписи у полей, контраст текста не ниже 4,5:1, цвет не единственный носитель смысла.
- NFR-8. Браузеры: актуальные Safari, Chrome, Firefox на десктопе и телефоне.
- NFR-9. Развёртывание: `docker compose up` поднимает всё, миграции применяются при старте, есть healthcheck.
- NFR-10. Резервные копии: дамп базы по кнопке и командой.

## 5. Вне объёма первой версии

Торговые операции, подключение криптобирж по ключу, импорт CSV, xpub для Bitcoin, свои узлы, лента уведомлений в интерфейсе, интерфейс управления пользователями, налоговые отчёты, бэктесты, светлая тема, нативные приложения. Полный список в `BACKLOG.md`.

## 6. Открытые вопросы к владельцу

1. Доступен ли API Т-Инвестиций с адреса NAS. Если нет, запросы идут через прокси, см. `05-integrations.md`.
2. По какому HTTPS-адресу будет открываться сервис. Пасскеи работают только в защищённом контексте и привязаны к домену, см. `07-auth-security.md`.
3. Какие сети крипты нужны в первой версии. По умолчанию: Bitcoin, Ethereum, Arbitrum, Base.
4. Часовой пояс отображения. По умолчанию берётся из браузера при первом входе.
