## Журнал

### Фаза 0

- [x] 1. Проект и инструменты: Next 16.4, TS 6.0 strict, ESLint flat, Prettier, Vitest, Playwright (desktop 1440, phone 390)
- [x] 2. Docker Compose: web + worker, один образ, том `./data` с файлом SQLite, `SREZ_PLATFORM` (по умолчанию linux/amd64). better-sqlite3 берёт готовые prebuilds, компилятор в образе не нужен
- [x] 3. Drizzle и миграции: `db()` с WAL и busy_timeout, таблица `logs`, FTS5 отдельной ручной миграцией, web применяет миграции при старте
- [x] 4. Воркер: своя очередь (`src/jobs/queue.ts`): атомарный захват через UPDATE … RETURNING, singleton-ключи частичным уникальным индексом, повторы с backoff, перехват задач с истёкшей блокировкой, расписания на croner в UTC (пропущенные запуски схлопываются в один). Тестовая задача `system.heartbeat` раз в минуту
- [x] 5. Логгер: pino, дочерние логгеры по источникам, редактор секретов на любой глубине (formatters, по окончанию имени поля: token, password, secret, authorization, cookie, key), пакетная запись в `logs` (100 строк или 1 с), `x-request-id` из `src/proxy.ts`, ошибки сервера через `onRequestError`. Проверено в Docker: heartbeat пишет строку с `job_id`, остановка по SIGTERM сбрасывает буфер
- [x] 6. Токены и базовые компоненты: токены в `@theme` (`src/app/globals.css`), Onest и JetBrains Mono через `next/font`, 18 компонентов в `src/components/ui` (Select, Segmented, ConfirmDialog, Toast на Radix; чекбокс и радио нативные, как в макетах), витрина `/dev/ui`
- [x] 7. Каркас и маршруты: боковое меню от 900 px и закреплённая нижняя панель с безопасной зоной, все маршруты карты экранов заглушками с номером фазы, `/more`, `/analytics` → `/analytics/risk`, 404 и страница ошибки, фавикон. Карточка в меню показывает «Нет источников» до фазы 4, логин и «Выйти» появятся в фазе 1. e2e: навигация на 1440 и 390, нет горизонтальной прокрутки, видимый фокус

### Фаза 1

Решения, согласованные с владельцем 2026-10-08:

| Решение | Причина |
|---|---|
| Резервные коды 2FA хранятся зашифрованными, не хэшами. `07`, раздел 3 поправлен | Better Auth сверяет коды расшифровкой |
| Сессия без «запомнить»: кука до закрытия браузера, не дольше 24 ч, без продления. `07`, раздел 5 поправлен | Поведение `rememberMe: false` в Better Auth |
| Email пользователя — заглушка `<логин>@local.invalid` | `user.email` обязателен в схеме Better Auth |
| Блокировка по логину своя: хук перед `/sign-in/username` + `login_attempts` | В Better Auth её нет |
| Поля `passkey.lastUsedAt`, `session.loginMethod`, `user.passwordChangedAt` через `additionalFields` | Их показывает макет `Security` |
| QR-код — пакет `uqr` | Согласовано |
| Лимит 20 запросов в минуту на вход, в памяти web | Один процесс |
| Заголовки безопасности и CSP — в фазе 10 | По плану |
| Порт web по умолчанию слушает только `127.0.0.1` (`SREZ_BIND`) | Без адреса сокета `X-Forwarded-For` подделывается при прямом доступе |
