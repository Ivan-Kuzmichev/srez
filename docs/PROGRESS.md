Решения: цена входящей монеты — закрытие дня по CoinGecko; бесплатный API даёт год истории, для более старых переводов берётся самая ранняя известная цена (себестоимость приблизительная). Растущий баланс: изменение за вычетом переводов дня — `accrual` в количестве токена по цене дня, позиция сходится с балансом сети. Обёртка (решение владельца 2026-10-09): `accrual` с количеством 0, начисление в базовой монете — в `accrued_interest`; стоимость не меняется — рост уже в цене обёртки (`03` и `04` дополнены). Первый день: одна запись «Начислено до подключения» = баланс − поступления + списания, у обёртки — только запоминается курс. Повтор в тот же день ничего не меняет. Начисление не внешний поток: «Вложено» не меняется (проверено тестом). Уменьшение без перевода (штраф, слэшинг) — `other` с пояснением; количество в журнале при этом не уменьшается — случай редкий, в бэклоге

Начисления на экранах. «Выплаты» — блок «Начисления по крипте» по `Payouts`/`MPayouts`: протокол и монета («Lido, stETH», «Aave, USDT»), сколько держится и в каких сетях, как начисляется (каждую секунду, раз в сутки, растёт курс к базовой монете), за текущий месяц и за год в рублях по цене дня и в монетах, прогноз на год по ставке последних 30 дней (меньше 7 дней истории — «мало истории»); в итоги выплат не входит; учитывает фильтр портфеля. Реестр токенов дополнен протоколом и способом начисления. После каждой синхронизации кошелька сразу считаются начисления дня — первая синхронизация записывает «начислено до подключения»
